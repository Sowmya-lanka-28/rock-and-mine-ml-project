# 🌊 Rock vs Mine Prediction using Machine Learning

## 📖 Project Overview

This project is a Machine Learning application that classifies sonar signals as either **Rock** or **Mine**. The model is trained using the Sonar Dataset and predicts the type of object based on reflected sonar signal measurements.

A Streamlit web application is included to provide an interactive interface where users can enter sonar feature values and receive real-time predictions.

---

## 🎯 Problem Statement

Identifying underwater objects is important for marine navigation and defense applications. This project demonstrates how Machine Learning can classify sonar returns into **Rock** or **Mine** categories.

---

## 📂 Dataset

The project uses the **Sonar Dataset**, which contains 60 numerical features extracted from sonar signals.

Target Classes:

* **R** → Rock
* **M** → Mine
